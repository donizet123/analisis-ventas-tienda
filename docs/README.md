# Análisis de ventas de una tienda comercial

## Descripción
Proyecto de análisis de datos desarrollado con Python, MySQL y Power BI, utilizando un conjunto de datos simulado de ventas de una tienda comercial.

## Objetivo
Analizar el comportamiento de las ventas para identificar los productos con mayores ingresos, evaluar el rendimiento comercial y facilitar la toma de decisiones mediante indicadores y visualizaciones.

## Herramientas utilizadas
- **Python (Pandas):** limpieza, transformación y análisis exploratorio.
- **MySQL:** almacenamiento y consultas de datos.
- **Power BI:** creación de un dashboard interactivo.
- **Git y GitHub:** control de versiones y publicación del proyecto.

## Proceso realizado
1. Importación y exploración de datos.
2. Identificación y tratamiento de valores nulos, duplicados y registros inconsistentes.
3. Cálculo de ingresos por venta.
4. Importación de datos limpios a MySQL.
5. Consultas SQL para analizar ventas, productos y categorías.
6. Desarrollo de un dashboard interactivo en Power BI.

## Indicadores del dashboard
- Ingresos totales.
- Unidades vendidas.
- Número de operaciones.
- Ticket promedio.
- Ingresos por producto, categoría, distrito y vendedor.

## Nota
Los datos utilizados son simulados y tienen fines educativos y de portafolio.
